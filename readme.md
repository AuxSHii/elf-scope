# elfScope

elfscope is a stand-alone command line ELF[executable and linkable format] binary inspector written in c99.
it parses 32bit and 64bit ELF binaries in both littile-endian and big-endian encodings without relying on external parsing libraries (`libelf` , `bfd` , or `<elf.h>`)
